Graph Algorithms & Fundamentals

Types of Graphs

Undirected Graph: Edges have no direction — connection is bidirectional. Facebook friendships are undirected.

Directed Graph (Digraph): Edges have direction (one-way). Twitter follows are directed.

Weighted Graph: Edges have numerical weights/costs. Google Maps distances are weighted.

Unweighted Graph: All edges have equal weight (considered 1).

Cyclic Graph: Contains at least one cycle (path that starts and ends at same vertex).

Acyclic Graph: No cycles. Trees are acyclic graphs.

Connected Graph: Path exists between every pair of vertices.

Disconnected Graph: At least two vertices with no path between them.

Complete Graph: Every vertex is directly connected to every other vertex.

📌 Key: V = Vertices, E = Edges

Breadth-First Search (BFS)

How it works: BFS explores all neighbors at the current depth before moving to the next level. It uses a Queue data structure (FIFO).

Algorithm Steps: 1. Start from source vertex, mark as visited and enqueue. 2. Dequeue a vertex, visit all unvisited neighbors, mark visited and enqueue them. 3. Repeat until queue is empty.

Applications: Shortest path in unweighted graphs, web crawling, social networking (finding friends within K levels), GPS navigation, broadcasting.

Example: Starting from A, BFS visits: A → B, C → D, E (level by level)

⏱ Time: O(V+E) | 💾 Space: O(V)

Depth-First Search (DFS)

How it works: DFS explores as far as possible along each branch before backtracking. It uses a Stack (or recursion).

Algorithm Steps: 1. Start from source vertex, mark as visited. 2. Recursively visit first unvisited neighbor. 3. Backtrack when no unvisited neighbors remain.

Applications: Detecting cycles, topological sorting, solving mazes, finding connected components, pathfinding, tree traversals.

Example: Starting from A, DFS visits: A → B → D → E → C (deep dive first)

⏱ Time: O(V+E) | 💾 Space: O(V) for recursion stack

Other Important Algorithms

Dijkstra's Algorithm: Finds shortest path in weighted graphs (non-negative weights). Uses priority queue. Time: O((V+E) log V)

Bellman-Ford: Shortest path that handles negative weights. Time: O(V×E)

Floyd-Warshall: All-pairs shortest path. Time: O(V³)

Kruskal's/Prim's: Minimum Spanning Tree (MST) algorithms.

Topological Sort: Linear ordering of vertices in DAG. Used in task scheduling.

Kahn's Algorithm: BFS-based topological sorting using in-degree counts.

BFS vs DFS - Detailed Comparison

BFS
  • Uses Queue (FIFO)
  • Finds shortest path (unweighted)
  • Level-order traversal
  • More memory for wide graphs
  • Better for closer targets
DFS
  • Uses Stack/Recursion (LIFO)
  • Does NOT guarantee shortest path
  • Depth-first traversal
  • Less memory for deep graphs
  • Better for finding existence
💡 Tip: Use BFS for shortest path in unweighted graphs. Use DFS for cycle detection and topological sorting.
