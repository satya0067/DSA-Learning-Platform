How It Works

1. Build Max Heap: Rearrange array into a binary heap where each parent > children.
2. Extract Max: Swap root (max) with last unsorted element.
3. Heapify: Restore heap property on reduced heap.
4. Repeat until all elements are sorted.

Key Properties

  • In-place sorting algorithm
  • Not stable (relative order of equal elements not preserved)
  • Excellent for large datasets
  • Guaranteed O(n log n) performance
  • Used in priority queues and selection algorithms

Heap Sort Step-by-Step Operations

  1. Build Max Heap: Starting from the last non-leaf node, heapify each node up to the root. This ensures the largest element is at index 0.
  2. Swap Root with Last: Move the maximum element (root) to the end of the unsorted portion. This element is now in its final sorted position.
  3. Reduce Heap Size: Decrease the heap size by 1 (exclude the sorted elements).
  4. Heapify Root: Restore the max-heap property by bubbling the new root down to its correct position.
  5. Repeat: Continue steps 2–4 until the heap size is 1. The array is now fully sorted in ascending order.
