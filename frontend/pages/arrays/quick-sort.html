Quick Sort Algorithm

1. Pick a Pivot: Choose an element (typically last element) as pivot.
2. Partition: Rearrange array so elements less than pivot go left, greater go right.
3. Recursively Sort: Apply the same process to left and right subarrays.
4. Time Complexity: O(n log n) average, O(n²) worst (rare with good pivot selection).

Complete Implementation

function quickSort(arr, low = 0, high = arr.length - 1) {
    if (low < high) {
        const pivotIndex = partition(arr, low, high);
        quickSort(arr, low, pivotIndex - 1);
        quickSort(arr, pivotIndex + 1, high);
    }
    return arr;
}

function partition(arr, low, high) {
    const pivot = arr[high];
    let i = low - 1;
    
    for (let j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            [arr[i], arr[j]] = [arr[j], arr[i]];
        }
    }
    [arr[i + 1], arr[high]] = [arr[high], arr[i + 1]];
    return i + 1;
}

// Example usage:
const arr = [6, 2, 9, 1, 8, 3];
console.log(quickSort([...arr])); // [1, 2, 3, 6, 8, 9]

💡 Tip: Quick Sort is often faster in practice than Merge Sort due to better cache locality!
