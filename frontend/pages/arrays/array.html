Arrays · Water Breathing First Form

What is an Array?

In data structures, an array is a sequence of elements stored consecutively in memory — like flowing water through a channel. Arrays provide direct indexed access, making them the foundation for many algorithms and higher-level structures.

Why arrays matter in DSA

Arrays are the first step in learning algorithmic thinking. They are used for sorting, searching, indexing, buffering, and building more complex structures like heaps, hash tables, and matrices. Master the First Form to unlock all future breathing techniques!

Core Array Operations

  • Access — read any element by index in O(1) time.
  • Traverse — visit every element sequentially in O(n) time.
  • Insert — add a new value at a specific position (O(n) time due to shifting).
  • Delete — remove an element and shift remaining elements (O(n) time).
  • Search — locate a value using linear search (O(n)) or binary search (O(log n)) for sorted arrays.

Searching Techniques

Arrays support multiple search operations depending on whether the data is sorted or unsorted.

  • Linear Search — compare each element in order until the target is found; best for unsorted arrays.
  • Binary Search — compare the target to the middle element, then narrow the search to the left or right half of a sorted array.
  • Jump Search — jump ahead by fixed blocks, then perform a linear scan inside the block where the target could exist.
  • Interpolation Search — estimate the likely position of the target in a sorted array based on its value distribution, then adjust the search range.

Search Operations:

Compare — check array values against the target.

Move — advance through the array using sequential or jump steps.

Narrow — limit the search range based on sorted order or estimated position.

Sorting Techniques

Sorting arrays organizes data and unlocks faster search and more advanced algorithms.

  • Bubble Sort — compare adjacent items and swap them if out of order; repeat until the list is sorted.
  • Selection Sort — repeatedly find the minimum value from the unsorted portion and swap it into position.
  • Insertion Sort — build a sorted prefix by inserting each new element into the correct position.
  • Merge Sort — split the array into halves, sort each half, then merge the sorted halves back together.
  • Quick Sort — choose a pivot, partition elements into lower and higher groups, then sort each partition recursively.

Sort Operations:

Compare — evaluate relative order of two elements.

Swap — exchange positions of elements when needed.

Divide — split the array for divide-and-conquer methods.

Array Operations & Complexities

Access

Access any element directly using its index.

Time: O(1) Space: O(1)

Search

Linear search: check each element one by one.
Binary search: requires sorted array.

Linear: O(n) Binary: O(log n)

Insert

Insert at position requires shifting elements to the right.

Time: O(n) Space: O(1)

Delete

Delete at position requires shifting elements to the left.

Time: O(n) Space: O(1)

Linear Search · Water Breathing Eighth Form

How it works: Linear search checks each element in the array one by one from left to right until the target is found or the array ends. It works on both sorted and unsorted arrays.


Algorithm Steps:

  1. Start from the first element (index 0)
  2. Compare the current element with the target value
  3. If match found → return the index position
  4. If no match → move to the next element
  5. Repeat steps 2-4 until the end of the array
  6. If end reached without finding → return -1 (not found)
Example Code (JavaScript): 
function linearSearch(arr, target) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] === target) {
            return i;  // Found at index i
        }
    }
    return -1;  // Not found
}

// Example usage
const numbers = [5, 8, 3, 7, 2];
const result = linearSearch(numbers, 7);
console.log(result);  // Output: 3
Best Case: O(1) | Worst Case: O(n) | Average: O(n)
