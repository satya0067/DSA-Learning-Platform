Algorithm with Example

How Selection Sort Works: At each pass, find the minimum element in the unsorted portion and swap it with the first unsorted element.

📝 Example: Sorting [64, 25, 12, 22, 11]

Pass 1: Find smallest in [64,25,12,22,11] → 11 at index 4
    Swap 64 and 11 → [11, 25, 12, 22, 64] ✅

Pass 2: Find smallest in [25,12,22,64] → 12 at index 2
    Swap 25 and 12 → [11, 12, 25, 22, 64] ✅

Pass 3: Find smallest in [25,22,64] → 22 at index 3
    Swap 25 and 22 → [11, 12, 22, 25, 64] ✅

Pass 4: Find smallest in [25,64] → 25 at index 3
    No swap needed → [11, 12, 22, 25, 64] 🎉 SORTED!

Implementation

function selectionSort(arr) {
    let n = arr.length;
    
    for (let i = 0; i < n - 1; i++) {
        let minIndex = i;
        
        // Find the minimum element in unsorted part
        for (let j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        
        // Swap if needed
        if (minIndex !== i) {
            [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
        }
    }
    return arr;
}

// Example
const arr = [64, 25, 12, 22, 11];
console.log(selectionSort([...arr])); 
// [11, 12, 22, 25, 64]

📌 Key Points:

  • Finds the minimum element in each pass
  • Swaps it with the first unsorted position
  • Performs at most n swaps (more efficient than Bubble Sort in swaps)
  • Not stable — equal elements may change order
