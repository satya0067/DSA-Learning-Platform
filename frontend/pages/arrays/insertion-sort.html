Insertion Sort - Detailed Explanation

1. Core Concept: Builds the final sorted array one element at a time by inserting each element into its correct position among previously sorted elements.

2. How It Works: Starts with the first element as "sorted". Then takes the next element and inserts it into the correct position by shifting larger elements to the right.

3. Real-life Analogy: Like sorting playing cards in your hand — you pick one card and insert it into the correct position among the cards you're already holding.

4. Time Complexity: O(n²) in worst case (reverse sorted), but O(n) in best case (already sorted) — very efficient for nearly sorted data!

5. Space Complexity: O(1) — sorts in-place without needing extra memory.

6. Stability: Stable algorithm — equal elements maintain their original relative order.

7. Best Use Case: Small datasets, nearly sorted arrays, or as part of hybrid algorithms (like Timsort used in Python).

8. Visual Clue: Watch the yellow tower (current element) move leftward as it finds its home among the green (sorted) towers!

Algorithm with Example

How Insertion Sort Works: Take each element and insert it into its correct position among the previously sorted elements.

📝 Example: Sorting [5, 2, 4, 6, 1, 3]

Step 1: Start with [5] as sorted portion
Step 2: Insert 2 → [2, 5]
Step 3: Insert 4 → [2, 4, 5]
Step 4: Insert 6 → [2, 4, 5, 6]
Step 5: Insert 1 → [1, 2, 4, 5, 6]
Step 6: Insert 3 → [1, 2, 3, 4, 5, 6] ✅ SORTED!

Detailed Pass 5 (Insert 1):
• Compare 1 with 6 → Shift 6 right
• Compare 1 with 5 → Shift 5 right
• Compare 1 with 4 → Shift 4 right
• Compare 1 with 2 → Shift 2 right
• Insert 1 at position 0 → [1, 2, 4, 5, 6]

Implementation

function insertionSort(arr) {
    let n = arr.length;
    
    for (let i = 1; i < n; i++) {
        let key = arr[i];
        let j = i - 1;
        
        // Shift elements greater than key to the right
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        
        // Place key in its correct position
        arr[j + 1] = key;
    }
    return arr;
}

// Example
const arr = [5, 2, 4, 6, 1, 3];
console.log(insertionSort([...arr])); 
// [1, 2, 3, 4, 5, 6]

📌 Key Points:

  • Great for small or nearly sorted arrays
  • Stable sort — preserves order of equal elements
  • In-place sorting — no extra space needed
  • Used in practice for hybrid sorting algorithms
