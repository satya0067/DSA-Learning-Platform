Trees · Mist Breathing First Form

A tree is a hierarchical data structure consisting of nodes connected by edges. The Binary Search Tree (BST) organizes nodes such that for any parent, the left subtree holds lesser values, and the right subtree holds greater values — like the clear, layered mist separating heaven and earth.

Mist Breathing Technique Rules

  • Left Branch: Concentration levels lesser than the parent node flow to the left.
  • Right Branch: Concentration levels greater than the parent node flow to the right.
  • No Duplicates: No two strikes can share the same strength level.
  • Mist Traversals: Reveal all hidden branches sequentially using pre-order, in-order, or post-order breaths.
